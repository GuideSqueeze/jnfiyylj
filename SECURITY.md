## 🛠 Troubleshooting

### Plugin not showing in DAW

```powershell
# Rescan plugins
# DAW > Preferences > Plugins > Rescan

# Check install path
# VST3: C:\Program Files\Common Files\VST3\Sylenth1.vst3

# Run installer as admin
# Right-click installer > Run as Administrator
```

### Preset browser empty

```powershell
# Reinstall soundbanks
# Download soundbanks from lennardigital.com > Extract to Documents\Sylenth1\Presets

# Reset preferences
# Delete C:\Users\[username]\AppData\Roaming\Sylenth1\Preferences.xml

# Check preset folder
# Sylenth1 > Menu > Preferences > Preset folder location
```

### High CPU usage

```powershell
# Reduce polyphony
# Voices = 8 (from 16) for less CPU

# Disable unused effects
# Turn off reverb/delay if not needed

# Increase buffer size
# DAW > Audio Settings > Buffer = 512 samples (reduces CPU load)
```
